Most Outstanding Research in Computer Engineering

Syringe Needle Collector Machine Using Arduino Micro-Controller

An automation solution designed to improve medical waste collection efficiency and safety using sensor-based detection and automated sorting mechanisms.

Arduino IDE C++ Embedded Systems Automation
Hardware prototype demonstration video

Project Objectives

Reduce direct human contact with used syringe needles during medical waste handling and standardize safe, automated collection at the point of disposal.

Technical Implementation

  • Arduino microcontroller logic written in C++ for actuator and sensor coordination
  • Sensor-based detection to trigger controlled collection cycles
  • Automated sorting and containment mechanisms to isolate hazardous sharps
  • Safety-focused physical enclosure designed for reliable operation
